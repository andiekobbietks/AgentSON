# Getting Support

AgentSON is an open-source project in alpha. Support is provided on a best-effort basis; there is no guaranteed response time or commercial support commitment.

- **Bug reports:** use GitHub Issues and include the version, environment, expected behaviour and a minimal sanitised reproduction.
- **Feature proposals:** open an issue describing the user problem before prescribing a large implementation.
- **Usage questions:** use GitHub Discussions if enabled; otherwise open a clearly labelled question issue.
- **Security concerns:** follow [SECURITY.md](SECURITY.md), not a public issue.
- **Commercial or managed-service enquiries:** do not assume that the open-source repository includes a hosted service or service-level agreement.

Please do not attach raw agent sessions, personal information, access tokens, private repository content or customer data. Create a minimal synthetic example instead.
