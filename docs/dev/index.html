Developer guide

Build, test and document AgentSON against the current v1.2 contract.

Project status: Alpha. The canonical interchange format is v1.2 JSONL. Check STATUS.md and the current pull request before assuming a proposed branch feature is already present on the default branch.

Development setup

git clone https://github.com/andiekobbietks/AgentSON.git
cd AgentSON
python -m pip install -e ".[dev]"
python -m pip check

Verification

python -m pytest -q
python -m build

Run focused tests while iterating. Run the complete supported matrix before merge. Install and test the built wheel outside the repository checkout so imports and schema resources resolve from the installed package.

Format contract

  • Canonical interchange is JSONL, one event per line, with stream-meta first.
  • Validate each event against spec/v1.2-entries.json.
  • spec/v1.2.json describes the materialised session-envelope/document representation, not the JSONL stream.
  • Preserve source ordering and provenance where available; report inferred, unavailable, redacted and unsupported information.
  • Keep imported prompts, commands, tool arguments and outputs inert.

Adapter work

Readers, importers and destination consumers are separate roles. For each reader, document the source version, capture method, fields mapped, source evidence retained, test fixtures and known fidelity gaps. Synthetic fixtures must be labelled as synthetic. Do not describe a module as fully supported merely because it exists.
