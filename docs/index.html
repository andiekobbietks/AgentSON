AgentSON

Portable, provenance-aware interchange for AI-agent session traces.

GitHub repository · README · Engineering standards · Operating procedures

Alpha / pre-release. Reader coverage, source fidelity and destination support vary. A valid archive does not prove complete capture, semantic equivalence, safe replay, runtime reconstruction or regulatory compliance.

What AgentSON does

AgentSON provides a local-first format and toolset for capturing, representing, validating, searching and inspecting AI-agent session histories. It separates the interchange contract from source readers, importers, destination consumers, transports and optional platform services.

Canonical v1.2 format

The canonical interchange wire format is JSONL: one JSON event per line, with stream-meta first. The established .agentson extension is retained. Individual events are validated against spec/v1.2-entries.json. The JSON session envelope in spec/v1.2.json remains a supported materialised/document representation; it is not the JSONL stream schema.

See the event ontology, ADR-015 and the interoperability architecture.

Quick start

python -m pip install agentson
agentson --help
agentson list --tool opencode
agentson export --tool opencode --session SESSION_ID --output ./sessions/
agentson validate ./sessions/

Use the installed CLI help for the exact commands and options in your package version.

Capabilities and limits

Capture and preserve

Source-specific readers map available records into a shared event vocabulary and retain source evidence where available.

Validate and inspect

Local tools validate supported representations and help inspect event history, provenance and known gaps.

Continue context

The resume workflow can create a reviewed Markdown context packet. The experimental OpenCode consumer has a limited archive-capsule handoff path.

AgentSON does not guarantee full source coverage, private reasoning capture, lossless conversion, arbitrary cross-harness resumption or automatic execution replay. Portability, reconstruction and resumption require different evidence.

Privacy and legal boundaries

Session records can contain personal data, credentials, private paths and confidential code. Review and redact before sharing. Pattern-based redaction is best-effort, not a complete detector. GDPR data-portability rights and EU AI Act duties depend on the circumstances; AgentSON does not determine legal applicability or certify compliance.
